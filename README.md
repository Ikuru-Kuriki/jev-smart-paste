# Jev Smart Paste

コピーした文章（メール署名、名刺の文字起こし、問い合わせ内容など）から、Web フォームの各項目に合う情報を選び出して自動入力する Chrome 拡張です。判断には TypeSafe AI の System One モデル **Jev** を使います。

## 仕組み

Jev は文章を生成せず、与えた選択肢から選んで確率を返す「決定モデル」です。そこでこの拡張は次の 3 段階で動きます。

1. **候補の切り出し**（`src/lib/candidates.js`）: 貼り付けた文章を、入力値になりうる断片に分けます。
   - メールアドレス・電話番号・郵便番号・URL・日付（正規表現）
   - `氏名：山田太郎`、`【会社名】〇〇`、タブ区切りなどの「項目名: 値」
   - `、` `,` `/` などで区切られた部分、`営業部 山田 太郎` → `山田` / `太郎` のような姓名の分割
   - 各行、段落、全文（段落と全文は textarea にだけ渡します）
2. **Jev に質問**（`src/lib/jev.js`）: ページ上のフォーム項目ごとに `choice` の質問を 1 つ作り、「この項目に入れるべき値はどれか」を候補（＋「該当なし」）から選ばせます。
   - `<select>` とラジオボタンは、候補の代わりにその項目自身の選択肢を渡します。
   - `type=email` / `tel` / `url` / `date` や郵便番号の欄には、形の合う候補だけを渡します。
   - 1 リクエストに最大 32 問・1 問あたり最大 64 択（ゲートウェイの上限）に分割して並列で送ります。
3. **入力**（`src/content/fill.js`）: 確率がしきい値以上の答えだけを入力します。React / Vue でも反映されるよう、ネイティブの setter で値を入れて `input` / `change` イベントを発火します。`type=date` には `2026年10月20日` → `2026-10-20` のように変換して入れます。

項目名は `<label>`、`aria-label(ledby)`、表の `<th>`、`<dt>`、直前のテキスト、`placeholder`、`name` の順に探します。

## インストール

1. このリポジトリを取得します。
2. Chrome で `chrome://extensions` を開き、「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」でリポジトリのフォルダを選びます。
4. 拡張機能の「オプション」で TypeSafe の API キーを入力して保存します。

## 使い方

- **ポップアップから**: フォームのあるページでツールバーのアイコン（または `Alt+Shift+V`）を押し、文章を貼り付けて（「クリップボードから貼り付け」も可）「フォームに自動入力」を押します。入力された項目と確率が一覧で出ます。「元に戻す」で入力前の状態に戻せます。
- **右クリックから**: ページ上の文章を選択して右クリック →「選択したテキストでフォームを自動入力 (Jev)」。

## 設定

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| API キー | なし | TypeSafe の API キー。拡張機能のローカルストレージにだけ保存されます。 |
| 入力する最低確率 | 0.5 | Jev が選んだ候補の確率がこれ未満なら入力しません。 |
| 入力済みの項目も上書きする | オフ | オフのときは空欄の項目だけを対象にします。 |
| エンドポイント / モデル | `https://api.typesafe.ai/v1/systemone` / `jev-latest` | Jev 互換の別ゲートウェイを使う場合に変更します（保存時にそのホストへのアクセス許可を求めます）。 |

## プライバシー

- 貼り付けた文章と、フォーム項目のラベル・選択肢が Jev API に送信されます。パスワード欄・hidden 欄・チェックボックスは対象外です（利用規約への同意などを勝手にチェックしないため）。
- ページへのスクリプト注入は、ポップアップか右クリックメニューを使ったタブに対してだけ行います（`activeTab`）。

## 開発

```sh
npm install
npm test           # 候補抽出・質問の組み立て・回答の解釈の単体テスト
npm run test:e2e   # 拡張を Chromium に読み込み、モックの Jev サーバーでサンプルフォームを埋める E2E テスト
```

```
manifest.json
src/
  background.js        # 全体の流れ（項目取得 → 候補抽出 → Jev → 入力）、右クリックメニュー
  lib/candidates.js    # 文章から入力値の候補を切り出す
  lib/jev.js           # Jev への質問の組み立て、API 呼び出し、回答の解釈
  content/fill.js      # ページ内: フォーム項目とラベルの収集、値の入力、元に戻す
  popup/               # ポップアップ UI
  options/             # 設定画面
test/
```
